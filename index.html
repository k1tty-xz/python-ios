Install

  1. Download the package that matches your setup from the releases page.
  2. Open the file in your package manager, or run dpkg -i followed by the file name.
  3. Check the install by running your interpreter with --version.

What is inside

Python.framework, the standard library without test modules, and pip. pip has no standalone command, so run it as python3 -m pip.

Every build starts from the official CPython source, verified against a pinned SHA-256. The interpreter, the framework and each extension module are signed ad hoc. GitHub Actions builds both packages on every push.
